# AI Resume Analyzer

AI-powered Resume Analyzer that analyzes a resume and provides an ATS score along with strengths, weaknesses, missing skills, and improvement suggestions.

## Features

- User Registration and Login
- JWT Authentication
- Resume PDF Upload
- AI-powered Resume Analysis
- ATS Score
- Strengths Detection
- Weaknesses Detection
- Missing Skills Detection
- Resume Improvement Suggestions

## Tech Stack

### Frontend
- React.js
- Axios
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- JWT
- Multer

### AI
- Groq API
